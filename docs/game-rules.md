# ゲーム仕様書：ダイイングメッセージ (Dying Message)

## 1. 概要
本ゲームは、被害者1名と探偵（1名〜複数名）に分かれて協力し、被害者が残したダイイングメッセージ（ヒントカードの組み合わせ）を手がかりに、事件の「犯人の職業」「凶器」「動機」の3つを特定する協力型推理ゲームです。
1台の端末を全員で参照・操作するパス＆プレイ方式で進行します。

---

## 2. プレイヤーと役割
- **プレイ人数**：2名以上
- **役割（役職）**：
  - **被害者（1名）**：お題（正解の職業・凶器・動機）を知っている唯一のプレイヤー。メッセージ（ヒント）を作成して探偵たちに伝える。
  - **探偵（1名〜複数名）**：被害者のメッセージを解読し、議論して誤った選択肢を除外していく。

---

## 3. カードと場の設定（セットアップ）

### 3.1 お題カードの配置と盤面レイアウト
- ゲーム開始時、カードプール（各19〜20種類以上）の中から、以下の3つのカテゴリごとに **ランダムに9枚ずつ**（計27枚）が選出され、場に配置されます。
  1. **職業**（9枚）
  2. **凶器**（9枚）
  3. **動機**（9枚）

**【レイアウト仕様】**
- カードはカテゴリごとに **「職業（行1）」「凶器（行2）」「動機（行3）」の横一列（3行）** で配置する。
- カード1枚あたりのサイズを大きく（十分なカード幅と高さ）確保して配置する。
- **各行（カテゴリ）の右端エリア** には、被害者がそのカテゴリをターゲットに設定して出したヒントカード（ダイイングメッセージ）を配置する専用スロット（最大2組分）を設ける。

### 3.2 お題の決定
並べられた27枚の中から、**各カテゴリ1枚ずつ（計3枚）** が「正解（事件の真実）」としてシステムによりランダムに選ばれます。
- 正解：[ 職業: 1枚 / 凶器: 1枚 / 動機: 1枚 ]

### 3.3 ヒントカード（手札）の仕様と管理
- 被害者には、メッセージ作成用のひらがなヒントカード（A群カード・B群カード）が初期手札として配られます。
- **初期手札**：ゲーム開始時、被害者は **A群カード 6枚**、**B群カード 6枚** を所持した状態でスタートする。
- **文字表記**：ヒントカードに書かれているテキストは **すべて「ひらがな」** とする。
- **カードの消費**：ヒントとして選択・提示されたヒントカードは、被害者の手札選択肢から除外（消費）される。
- **カードの補充**：探偵側が推理を提出（6枚確定）した後、被害者の手札にヒントカードAおよびBが **それぞれ1枚ずつランダムに補充** される。

---

## 4. 勝利・敗北条件
- **勝利条件**：
  - 議論と除外を繰り返し、場のカードが **「職業1枚」「凶器1枚」「動機1枚」**（すべて正解カード）のみ残った状態にする。
- **敗北条件**：
  - **探索カウンタ**（最大4・開始時1）の状態で、探偵側が正解カードを含む6枚を選んで推理に失敗するとゲームオーバーとなる。推理失敗のたびに探索カウンタは1増える。

---

## 5. ゲームの進行フロー

### Phase 1: 設定フェーズ（セットアップ＆お題確認）
1. プレイヤー名を入力し、役割（被害者1名、残りを探偵）を任意で指定する。
2. 全カードプールから「職業」「凶器」「動機」がランダムに9枚ずつ選出され、カテゴリごとに横一列で配置される。
3. **お題確認用クッション画面**を挟み、被害者のみがお題（正解の職業・凶器・動機）を確認して覚える。

### Phase 2: 事件発生（被害者ターン：初回ヒント作成）
1. 被害者は手札（A群6枚、B群6枚）を使い、**「職業」「凶器」「動機」の3カテゴリすべてに対して、順番を問わず1組ずつ（計3組）のヒントを作成・提出** する。
2. 提出されたヒントは各行の右端エリアに配置される（Aカード: 薄赤、Bカード: 薄青、縦幅半分）。
3. 使用した3組のヒントカードは手札から削除される。

### Phase 3: 推理・決定（探偵ターン：6枚選択）
1. 探偵たちは盤面および各行右端に提示されたダイイングメッセージを確認し、話し合う。
2. 探偵たちは、正解ではないと思うカードを **必ずちょうど6枚** 選択して確定する。

### Phase 4: 結果発表・判定
1. 選ばれた6枚のカードを判定する。
   - **成功（6枚とも正解が含まれていない場合）**：
     - 選ばれた6枚のカードは場から完全除外（グレーアウト）される。
     - ダイアログメッセージ：「真実への接近！」
   - **失敗（6枚の中に正解が1枚でも含まれていた場合）**：
     - **探索カウンタが +1** される（最大4）。
     - **【パターンA適用】** 選んだ6枚は**除外されず、すべて場に残ったまま**次ターンへ進む。
     - ダイアログメッセージ：「捜査の迷走……（失敗 +1）」
2. **勝敗判定**：
   - 残りカードが「職業1枚・凶器1枚・動機1枚」になれば **探偵＆被害者チームの勝利！**（ダイアログ：「隠された真実がすべて暴かれた。」）
   - 探索カウンタが最大（4）の状態で推理に失敗したら **ゲームオーバー（敗北）**（ダイアログ：「迷宮入り — 犯人の完全勝利」）
3. **継続の場合**：
   - 被害者の手札に**ヒントカードA・Bがそれぞれ1枚ずつ補充**される。
   - 2ターン目以降の被害者ターン（Phase 2）では、まだヒントが2個に達していないカテゴリを1つ選んで **1組だけ** ヒントを追加提出し、Phase 3 へ進む。
